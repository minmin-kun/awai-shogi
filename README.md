# あわい将棋

両者が同時に指し手を予約する、ブラウザ用の変則将棋。CPU練習とルームコードでのオンライン対戦に対応します。

## ローカル起動

Node.js 24以上。追加パッケージは不要です。

```powershell
cd awai-shogi
npm start
```

http://localhost:3000 を開きます。ルームは `.data/rooms.sqlite` に保存します。`PORT` 環境変数でポート変更可能。別の端末から対戦する場合は、両者が接続できる同じサーバーのURLを使ってください。インターネット向け運用にはHTTPSを設定したホスティングが必要です。

## 確定したルール

- 毎ターン、両者が30秒以内に指し手を同時予約。両者の確定時点で移動開始。未確定のまま時間切れになるとパス。
- 現在の先手、後手の順に実行。先手が1枚以上取ると、次のターンの先手と後手が交代。後手が取っても交代しない。
- 開始後手だけが、対局中一度「二度打ち」ボタンを押して2手を予約できる。同じ駒でも異なる駒でもよい。自分の移動順に2手連続で実行。ボタンだけでは未消費。2手の確定で消費し、不発でも戻らない。
- 予約時は駒の動く方向・距離、所有者、持ち駒の在庫、成りや行き所のない駒の制限を判定する。移動先・経路の占有や二歩など、先行する移動で変わりうる条件は実行時に判定する。現在は動けないマスも「条件付き予約」として選べる。飛車・角・香の進路が先行手で空けば移動でき、持ち駒も移動先が空けば打てる。実行時にまだ動けなければ不発となり、元の位置と持ち駒は変わらない。取られた駒は復活しない。
- 2手目は自分の1手目が成功したと仮定した盤面で選択する。両者の予約確定後は各手の実行直前に合法性を再判定。1手目が不発で、2手目の予約元にも駒が存在しなければ、2手目も不発になる。予約は駒のIDに結び付け、別の駒が予約元に入っても動かさない。移動先の相手駒が移動していた場合、空きマスへの移動として成立する。
- 王の捕獲で勝利。王手・詰みによる行動制限と打ち歩詰め、千日手・持将棋の自動判定はない。駒の動き、成り・強制成り、持ち駒、二歩、行き所のない駒の制限を実装。
- 二度打ちの先の1手で王を取った場合は即終了し、後続の予約は実行しない。

## 構成と検証

- `src/engine.js`: ブラウザ／サーバー共通のルールエンジン。
- `src/api.js`: 参加トークンのSHA-256照合、相手の予約を隠すレスポンス、サーバー時刻、競合制御による対局処理。
- `server.mjs`: SQLiteによるローカルサーバー。
- `public/`: レスポンシブUI。練習用CPUは簡単な評価関数を使用。
- `scripts/build.mjs`: Cloudflare Workers用にアセットとエンジンを単一ESMへ組み込み。SitesではD1の`DB`バインディングと `drizzle/` のマイグレーションを使用。

```powershell
npm test
npm run build
```

ルームは24時間有効。参加トークンはブラウザのsessionStorageに保存し、同じタブの再読み込みから復帰可能。対局状態はサーバーに保存。ポーリングにより両者の確定や時間切れを解決するため、全員が画面を閉じている間は実行されず、次回アクセス時に期限切れのターンを解決します。

オンラインの思考時間は各プレイヤーのアニメーション完了通知 (`POST /ready`) 後にサーバー側で30秒を開始します。両者の確定、または各自の時間切れによるパスが揃ってから次のターンへ進みます。通知の再送・再読み込みでは既存の時計を延長しません。切断した画面から完了通知が届かない場合は、10秒の準備猶予後にその側の時計を開始し、対局が停止し続けるのを防ぎます。

予約は実際の駒を動かさず、半透明の駒・番号付き矢印で表示します。二度打ちの2手目は半透明の予約位置から選択できます。取り消しボタンは末尾の1手だけを戻し、2手ある場合は全取り消しも可能です。不発時には理由をイベントと棋譜に保存・表示します。スマートフォンでは基本ルールを折りたたみ、対局開始時にも閉じます。

盤上の駒や持ち駒をタップすると、名前・説明・移動図と、成った後の説明・移動図を表示します。自分と相手の向きに合わせて図を反転します。対局開始前や確定後にも説明を確認でき、説明だけの操作で指し手を予約することはありません。

オンライン対戦は認証済みのリクエストで接続を確認します。状態保存は各側3秒間隔を上限とし、12秒以上応答がない側を「応答なし」と表示します。切断とバックグラウンドでの通信抑制は区別できないため、切断を断定せず、その可能性を案内します。自分の通信失敗・オフライン・再接続中と、相手の応答状態は分けて表示し、復帰時は自動同期します。通信状態は思考時間や確定済み指し手を変更しません。

公開先のアクセス権と対戦ルーム参加は別です。Sitesの初期公開は所有者限定のため、別アカウントの友だちと試すにはSites側の共有設定も必要です。
