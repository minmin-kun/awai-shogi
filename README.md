# あわい将棋

両者が同時に指し手を予約する、ブラウザ用の変則将棋。CPU練習とルームコードでのオンライン対戦に対応します。

## ローカル起動

Node.js 24以上。追加パッケージは不要です。

```powershell
cd awai-shogi
npm start
```

http://localhost:3000 を開きます。ルームは `.data/rooms.sqlite` に保存します。`PORT` 環境変数でポート変更可能。別の端末から対戦する場合は、両者が接続できる同じサーバーのURLを使ってください。インターネット向け運用にはHTTPSを設定したホスティングが必要です。

## 確定したルール

- 毎ターン、両者が30秒以内に指し手を同時予約。両者の確定時点で移動開始。未確定のまま時間切れになるとパス。
- 現在の先手、後手の順に実行。先手が1枚以上取ると、次のターンの先手と後手が交代。後手が取っても交代しない。
- 開始後手だけが、対局中一度「二度打ち」ボタンを押して2手を予約できる。同じ駒でも異なる駒でもよい。自分の移動順に2手連続で実行。ボタンだけでは未消費。2手の確定で消費し、不発でも戻らない。
- 2手目は自分の1手目を仮実行した盤面で選択する。両者の予約確定後は、その時点の盤面で合法性を再判定。駒の消失・移動先や経路の閉塞による不正手は不発。移動先の相手駒が移動していた場合、空きマスへの移動として成立する。
- 王の捕獲で勝利。王手・詰みによる行動制限と打ち歩詰め、千日手・持将棋の自動判定はない。駒の動き、成り・強制成り、持ち駒、二歩、行き所のない駒の制限を実装。
- 二度打ちの先の1手で王を取った場合は即終了し、後続の予約は実行しない。

## 構成と検証

- `src/engine.js`: ブラウザ／サーバー共通のルールエンジン。
- `src/api.js`: 参加トークンのSHA-256照合、相手の予約を隠すレスポンス、サーバー時刻、競合制御による対局処理。
- `server.mjs`: SQLiteによるローカルサーバー。
- `public/`: レスポンシブUI。練習用CPUは簡単な評価関数を使用。
- `scripts/build.mjs`: Cloudflare Workers用にアセットとエンジンを単一ESMへ組み込み。SitesではD1の`DB`バインディングと `drizzle/` のマイグレーションを使用。

```powershell
npm test
npm run build
```

ルームは24時間有効。参加トークンはブラウザのsessionStorageに保存し、同じタブの再読み込みから復帰可能。対局状態はサーバーに保存。ポーリングにより両者の確定や時間切れを解決するため、全員が画面を閉じている間は実行されず、次回アクセス時に期限切れのターンを解決します。

公開先のアクセス権と対戦ルーム参加は別です。Sitesの初期公開は所有者限定のため、別アカウントの友だちと試すにはSites側の共有設定も必要です。
